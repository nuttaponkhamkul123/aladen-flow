Custom Header


Feature
Custom header is the feature that user can drag any components to the header and save it as a custom header. 
basically like container but carousel

User can add subsection into custom header
User can edit and set properties for each component in the header such as: 
- Logo
- Navigation links
- CTA button
- Search bar
- Custom block

It's also possible to add a carousel of custom blocks to the header. The carousel can be configured to rotate automatically or manually.
can customize arrow button and behavior
can customize dot button and behavior
can cusomize show dot, show arrow, show prev next, show current slide
